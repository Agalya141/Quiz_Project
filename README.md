# Quiz Game

A JavaScript quiz game with a start screen, five questions and a result screen. Built with plain HTML, CSS and JavaScript.

**Live demo:** _add your GitHub Pages link here_

## Features

- Start, quiz and result screens
- 5 multiple-choice questions about JavaScript basics
- Instant feedback: the correct answer turns green, a wrong pick turns red
- Live score and question counter
- Automatic move to the next question
- Result message based on the final score
- Restart button
- Responsive layout for mobile screens

## Built With

- HTML5
- CSS3 (flexbox, animations, media queries)
- JavaScript (DOM manipulation, arrays and objects, event listeners, `dataset`, `setTimeout`)

## What I Learned

- Switching between screens using `classList`
- Creating buttons dynamically with `createElement`
- Storing quiz data in an array of objects
- Using `dataset` to mark the correct answer
- Tracking state with variables like `currentQuestionIndex` and `score`
